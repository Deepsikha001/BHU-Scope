BHU-SCOPE AI - Module 1 (Authentication)
This starter frontend is built for Next.js (App Router) + TypeScript + Tailwind CSS.
Included:
Login page
Register page
Forgot Password page
Profile page
JWT-ready auth service placeholder
Reusable AuthLayout component
Connect these pages to your FastAPI backend endpoints:
POST /auth/login
POST /auth/register
POST /auth/forgot-password
GET /users/me
